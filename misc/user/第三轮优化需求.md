# 第三轮优化需求

## 概述

本文档是用户试用了第二轮优化后的软件后列出的第三轮优化需求。

## 交互和 UI

### 颜色

- Segment 的钢琴卷帘视图，其“Segment有效范围”的背景色现在是红色，改成与在逻辑轨道 Segment 背景色同款的相似颜色（颜色要浅），钢琴卷帘上的音符颜色，也改成同款的蓝灰色系，但选择状态的音符的颜色和边框仍然保持现在的红色。

### Segment 和 钢琴卷帘的鼠标指针与交互

- Draw 模式下，鼠标指针保持为默认指针；Select 模式下，鼠标指针换成十字（即现在的Draw模式用的指针），其余保持现状。

- Split 模式下，鼠标移到 Segment 上面，不应该变成上下左右那个指针，也不应该在 Segment 边界处变成左右的那个指针；应该在 Split 模式下，在 Segment 上面始终变成文本选择的那个指针。

- Draw 模式下，无论是 Segment 还是音符，在边界处鼠标指针应该变成相应指针；鼠标在对象的非边界位置，鼠标指针应该变成上下左右指针，且创建预览应暂时隐藏，直到移出。

- Select 模式下，不应该再能够拖拽、调整长度，相应的鼠标指针也不要变，这些操作应仅在 Draw 模式下可用。

- 两种模式下，单击对象都能仍然选择这个对象，这个行为不变。

- 拖拽或调整长度 Segment / 音符时，应能够预览拖拽位置和长度，就像预览创建位置那样。但是，拖拽或调整长度时，“创建”的预览要暂时隐藏，只显示拖拽/调整长度的预览。

- 加两个快捷键，在任何地方（除了文本编辑或其他需要的例外），键盘按下 d 为切换为 Draw 模式，按下 s 为 Select 模式，按下 e 为 Erase 模式。

- Select 模式下，不要再让双击创建Segment / 音符，这个功能没啥用且容易误操作。

- 不应允许用户处于任何模式都不是的状态。例如，逻辑轨道视图，用户可以让Draw/Select/Split/Erase都处于未激活状态。实际上不应该这样，这四个按钮应该是互斥的，且必须选择一个。Draw 激活时，再按下 Draw，不应该取消激活 Draw。钢琴卷帘同理。

### 粒度设置的下拉框 BUG

- 下拉框里选择后，粒度相应地确实有作用，功能是好的。

- 但是，最终框里的文字却没有相应的变化。

### 控件样式和 UI 问题

- 下拉框控件的右边的下箭头，好像是个符号，看起来很别扭，而且这个符号没有在垂直上居中。换成图标+垂直居中。

- 在钢琴卷帘中（Segment 和 Subvoice），右边的滚动条行为正常，但样式上，里面的条只露了个顶部头部。其他地方的滚动条是正常的。

- Bottom Panel 的诊断 Tab，上面的三个下拉框底部被截断了。

- Segment 钢琴卷帘视图的顶部，左侧的两个文字都没有垂直居中。
