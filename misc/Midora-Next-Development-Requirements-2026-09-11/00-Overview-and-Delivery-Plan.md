- 视图：MIDI Segment / Logical Segment / SubVoice；关联 Velocity / 参数 / MIDI Event / Tempo；不能只修一个宿主。
- 内容：空、单点、10 对象、稀疏 / 密集、同 Tick 重复、跨页、40 万选择、百万级对象、大型样本；大小规模命令语义一致。
- 编辑：创建、普通 / Ctrl 复制拖动、左右 resize、Properties、批处理、列表入口、Undo/Redo、精确碰撞、取消、旧 revision、Owner 删除。
- 渲染：冷 / 热页、边界外内容、缩放切换、选择层对齐、非空首帧、后台取消；保留已验收的局部失效 / 两级 Arrangement 概览策略。
- 性能：相同机器 / 样本 / 设置分别测冷暖 p50/p95/p99 交互耗时、UI 最长停顿、首内容时间、分配量、GC heap、Working Set、resident/spill/队列上限和关闭释放。不得只报单次平均值。
- 大型样本优先沿用 `9KX2 18 Million Notes.mid` 的 MIDI Out #23 密集区和 40 万 / 百万选择；运行该实验时须先确认样本路径存在。MIDI→Logical→SubVoice 路径不能省略。正式运行以进程树内存接近 9 GiB 为警戒并终止有失控趋势的探针，避免系统分页假死。
- 持久化 / 声音相关变更：Full/Incremental 等价、正式序列与 source trace、Format 1/2/3 重开、Save/Save Copy、失败原子性、试听停止所有权；UI 名称、颜色、Tab 重排不改 canonical/导出。
- UI 人工只做自动测试无法覆盖的布局、视觉、手感和声音确认；每轮给稳定编号小清单，不要求用户反复全软件遍历。DPI 100/125/150/200%、短窗、长名称、禁用状态作为统一视觉矩阵。

性能验收基线应在每个专题实施前重测，预算和可接受退化明确记录；本轮不承诺未经测量的百分比收益或耗时。不得为 R31 百分比、R28 Tab 数或 R11 染色增加全工程 UI 同步扫描。
