## Event Instrument 编辑

### 无法从左侧栏双击SubVoice切换右侧展示的SubVoice

期望：双击左侧栏SUBVOICES里面的某个Subvoice后，右侧的Subvoices的Tab应切换为对应选择的SubVoice编辑视图。

实际：不切换。导致现在无论如何都无法切换到想要编辑的SubVoice。

### 无法从左侧栏右键SubVoice弹出菜单

我需要删除、复制、剪切、粘贴等操作。我需要跨Event Instrument的SubVoice复制粘贴。

### Select Instrument in Inspector 不是好设计

我费了好大劲才找到Root Note应该在哪里配置。

直接把这些属性放在原来Lifecycle里面，然后把Lifecycle换个名字叫作"Configurations"，然后从上到下按照类别用大标题分类展示。原先的Lifecycle配置组保留。

### SubVoice的MIDI事件编辑需求变更

实际上使用中，我发现我并不需要现在的Add Curve和Add Event两种方式。而且这两种方式都有点难用。

对于任何事件，换成唯一一种最朴素的方式。

仍然是二维视图，但这里只能画一系列y-x点，一个x下不允许多个y。不再提供曲线->自动换算成点 的模式（多余，也难以应对复杂情况），也不再是一维的并列事件点（很难用，不直观）。一律是在二维画布画成什么点，最终就是什么点。

就像Velocity视图那样：允许单点上下拖动、允许鼠标左键拖动画任意线、允许Alt+鼠标左键拖动来强制画线以便在密集处中途开始画线；允许右键拖动来画成起终点决定的一段直线。

我们就把这个Add的按钮叫作“Add Event”，名字不变，并且把按钮的位置从钢琴卷帘顶部栏移动到事件视图的顶部栏的最右边。这样，钢琴卷帘上面就只需要一行的工具栏。Event / Curve Lane 的Tab名字也更换成 Event Lane。

## 杂项 UI 优化点

- Inspector中，bool类型的字段应该是个复选框，而不是自由文本编辑框。

- 一部分自定义弹窗，至少在Windows 11下，会露出Windows 11的原生窗口顶部白边；而有一部分弹窗却没有这个问题。弹窗样式应统一，我怀疑你不小心写了好几套。

- 一部分弹窗，高度不够高，导致底部的按钮被截断。但我怀疑这与露出了原生窗口顶部白边后的窗体高度行为有关系。
